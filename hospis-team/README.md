# Hospis OS — командная версия (тест)

Общая база выездной службы: каждый сотрудник входит под своим именем и паролем.

- **Врач и медсестра** видят только закреплённых за ними пациентов, отмечают «Был».
- **Заведующая и старшая медсестра** видят всех, закрепляют пациентов, ведут список сотрудников, смотрят «Отчёт» и выгружают его в Excel.

Сейчас это **тест на вымышленных данных**: 20 пациентов и 7 сотрудников придуманы. У всех тестовых сотрудников пароль `1111`. Реальных пациентов сюда не вносить, пока не выбран сервер в России и не согласовано с руководством.

## Где работает

Vercel: сайт + функция `api/index.ts`. Данные лежат одним файлом в закрытом хранилище Vercel Blob.

Переменные окружения на Vercel:
- `AUTH_SECRET` — случайная строка для подписи входа;
- `BLOB_READ_WRITE_TOKEN` — появляется сама при подключении хранилища Blob.

## Переезд на сервер в России (Timeweb, Yandex Cloud)

Тот же `api/index.ts` умеет хранить данные в обычном файле: без `BLOB_READ_WRITE_TOKEN` он пишет в `DATA_FILE` (по умолчанию `./hospis-data.json`). Нужен Node.js 22 и любой веб-сервер, который отдаёт папку `dist` и передаёт запросы `/api/*` в функцию `handle` из `api/index.ts`.

## Команды

- `npm test` — проверки
- `npm run build` — сборка в `dist`
