# Hospis OS 1.0

Приложение в Telegram для выездной работы: смены, пациенты на сегодня, завтра и неделю, новости и справка для всех сотрудников.

Вход: заставка, потом пароль. Пароль сейчас **petushok**. На телефоне его спрашивают один раз.

## Проверить на компьютере

```
npm install
npm run dev
```

Откройте `http://localhost:5173`, введите пароль и нажмите «Посмотреть на примере».

## Опубликовать

1. Загрузите **все файлы** архива в репозиторий GitHub. Папка `.github` нужна обязательно.
2. **Settings → Pages → Source: GitHub Actions**. Через 1–2 минуты сайт соберётся сам.
3. В @BotFather: `/mybots` → бот → **Bot Settings → Menu Button**. Впишите адрес сайта и добавьте в конце `?v=1`, например `https://логин.github.io/hospis-os/?v=1`.

Шаг 3 нужен **один раз**: новый адрес заставляет Telegram забыть старую копию из кэша. Дальше обновления приходят сами.

## Как работают обновления

Telegram хранит страницу приложения в кэше. Поэтому страница теперь только «загрузчик»: при каждом открытии она скачивает свежий `version.json` в обход кэша и запускает код, который в нём указан.

Чтобы выпустить обновление:

1. Поменяйте номер в `src/config.ts`: `APP_VERSION = '1.0.1'`.
2. Загрузите файлы на GitHub.

Кто откроет приложение — получит новую версию. У кого оно было открыто, обновится при возвращении в приложение.

## Новости и справка

Это два файла: `public/news.md` и `public/info.md`. Править их можно прямо на сайте GitHub (карандаш → Commit changes). Через 1–2 минуты изменения увидят все, приложение обновлять не нужно.

Новость:

```
## 30.10.2026 Заголовок
Текст. Пустая строка — новый абзац.
- пункт списка
```

`## 30.10.2026 ! Заголовок` — важная: красная и висит на главном экране.

В справке телефон в строке `| Имя | Должность | +7 900 000-00-00` становится кнопкой звонка.

## Пароль

```
npm run password -- новыйпароль
```

Потом загрузите файлы на GitHub. Все, кто входил по старому паролю, должны будут ввести новый. В коде хранится только отпечаток пароля.

Это защита от случайных людей, не от взломщика: без сервера надёжнее не сделать.

## Данные

- Пациенты и смены у каждого свои: в облаке Telegram и копией на телефоне. Другой сотрудник их не видит.
- Резервная копия: Настройки → «Скопировать» → вставить в «Избранное» Telegram. Восстановить: Настройки → «Восстановить из копии». Копии из старых версий приложения тоже подходят.
- Не кладите резервные копии в репозиторий.

## Команды
